标准、使用说明与等级选取

标准与范围

数据依据 GB/T 1184-1996《形状和位置公差 未注公差值》附录B 表B1~B4（等级值，单位 μm）与表1~4（未注公差值，单位 mm）整理；等级适用情况摘自机械设计手册“形位公差等级应用举例”（经嘉立创FA机械设计手册镜像核对）。等级值表覆盖主参数至 10000 mm（表B2 至 500 mm），未注公差值至 3000 mm。

使用方式

在左侧填写被测要素的参考尺寸：线性要素（面/线）填长度 L，回转要素（轴/孔）填直径 d(D)，对称中心要素填宽度 B 或长度 L；四张等级表同时按该值落段。未注公差值按主输入与短边尺寸分别落段，鼠标悬停各等级数值块可查看该等级适用情况。

结果与注意

等级值单位为 μm，未注公差值单位为 mm；卡片提示“超出范围”时表示该表不覆盖所填尺寸。本工具供学习参考，工程应用请以标准正文和校核为准。

未注公差的特殊规则

未注公差的特殊规则：平行度未注值 = 该处尺寸公差值 与 直线度/平面度未注值 中的较大者；圆度未注值 = 该处直径公差值（不大于径向圆跳动值）；圆柱度、同轴度、倾斜度、位置度、轮廓度未规定未注值。

不查等级表的项：位置度、线轮廓度、面轮廓度——按功能要求或配合公差换算；同轴度无未注值规定（极限情况可等于径向圆跳动未注值）。

取值关系参考

形状公差 < 方向公差 < 位置/跳动公差；平面度 ≈ (1/3~1/2)×平行度；平行度/垂直度 ≈ (1/3~1/2)×位置度；形位公差通常取对应尺寸公差的 50%~70%。

等级选用要点
  1. 满足功能要求前提下兼顾加工经济性，线对线/线对面的平行度、垂直度公差等级应低于面对面的等级。
  2. 面对面平行度/垂直度选级时被测面宽度应不大于长度的 1/2，大于则降低一级。
  3. 倾斜度无独立应用档位资料，参考垂直度档位选用。
  4. 鼠标悬停各等级数值块可查看该等级适用情况。
